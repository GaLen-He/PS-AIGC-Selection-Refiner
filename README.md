# Photoshop AIGC Selection Refiner

Photoshop AIGC Selection Refiner 是一个 Photoshop CEP 面板插件，用来把 Photoshop 里的选区、参考图和提示词提交到 AIGC 图像平台，并把生成结果自动回贴到原 PSD 中。插件本身不包含生图模型，也不保存 API Key；使用时需要填写自己的平台 URL 和 API Key。

## 主要功能

- **选区提交**：从当前 Photoshop 文档导出选区内容，连同提示词、参考图和模型参数提交到 AIGC 平台。
- **模型与参数面板**：连接平台后拉取可用模型和配置，按模型动态展示尺寸、数量、提示词、参考图等参数。
- **自动回贴结果**：轮询生成任务，下载结果后按原选区位置和尺寸回贴到 PSD，尽量保持原文档、画板和当前选择状态。
- **分层/背景生成支持**：支持分层结果、绿色背景识别、本地透明处理和失败层重试，减少生成结果回贴错位或层级错误。
- **选区快照与任务恢复**：提交时保存独立选区快照，面板重载后可继续查询已有任务，避免把结果贴到错误选区。
- **角落字符清理**：可选地对结果图角落水印/字符进行本地保守清理，并在需要时配合 Photoshop 内容识别修复。
- **静默导出与回贴优化**：针对大画布、画板、多文档切换和回贴闪动做了保护，降低提交、下载和回贴过程对当前工作的打扰。
- **本地回归测试**：提供 Node.js 测试覆盖网关请求、参数解析、选区几何、任务恢复、网络失败、分层回贴和字符清理等逻辑。

## 最近更新

- **0.5.30 更新**：新增【留边防水印（贴回自动裁掉）】和【上下 / 左右留边】选项。提交时可补约 8% 灰边，生成后裁回原选区，减少角落水印进入结果；同时优化单任务重试、任务恢复、透明结果贴回和错误提示。
- **0.5.16-0.5.29**：加入后台回贴助手、预建结果层、任务进度与恢复、先贴回后清理、签名安装包和更稳的自动升级 / 回退流程。
- **0.5.15**：优化大图提交与回贴流程。大图导出改用更快的 PNG 副本路径，回贴前由面板预缩放结果，减少 Photoshop 内部重绘和缩放负担。
- **0.5.14**：针对大画布和画板场景改为后台存储副本导出，减少原 PSD 中合并、裁切、撤销带来的可见闪动。
- **0.5.11**：增加双文档回贴遮罩，在结果回填、文档切换和刷新期间降低目标文档短暂暴露的概率。
- **0.5.x 系列**：持续完善选区快照、失败图片保留、任务恢复、角落字符清理、参考图上传和分层结果回贴。


## 项目结构

```text
cep/AIGCSelectionRefiner/        当前 CEP 插件主体
package/                         最新安装包源码、UXP 回贴助手、安装脚本和测试
cep/AIGCSelectionRefiner/js/     面板逻辑、网关客户端、分层计划和结果清理
cep/AIGCSelectionRefiner/host/   Photoshop ExtendScript 与本地辅助程序
src/                             早期 UXP 原型代码
test/                            Node.js 回归测试
tools/                           本地辅助工具和模拟网关
```

## 本地测试

```powershell
npm test
```

测试不会调用真实 AIGC 平台，也不会使用真实 API Key。

## 安全说明

- 不要提交真实 API Key、签名私钥、平台临时凭据或生成结果缓存。
- `.gitignore` 已排除构建输出、安装备份、签名私钥目录、接口响应快照和本机随机文件。
- 公开仓库中的平台地址使用占位示例；实际使用时请在面板里填写自己的 AIGC 平台 URL。
