# 0.5.19 后台回贴实施计划

**目标：** 回贴不选择其他文档；稳定的 0.5.14 提交导出保持不变。

**架构：** CEP 负责图片清理、缩放、缓存、任务恢复；配套 UXP 助手通过带独立随机令牌的本机连接接收任务，使用明确的 documentID 和 layerID 写入像素与蒙版。不发送平台 API Key 给助手。不采用截图遮罩，不自动降级到切换文档回贴。

**约束：** 仅修改此开发包。不开启调试模式、不重启 PS、不在真实 PSD 上运行探针、不提交付费任务。不保证未签名 UXP 插件可通过公司加载策略；安装能力与实际窗口行为未验证时必须明确标记。

## 实施步骤
- [x] 新增离线回归测试：非活动文档写入、蒙版坐标、图层归属、幂等、失败回滚、助手断线与身份验证。
- [x] 实现 `createWriter(photoshop, readAsset)` 与 `createBridge(options)`；请求中只传尺寸、定位、任务 ID 和已注册的本机像素资源。
- [x] 接入选区蒙版快照、分层即时回贴与恢复；临时资源退出即释放，待回贴蒙版随任务保留。
- [x] 添加保留其他插件配置的安装脚本与实验版说明；不直接覆盖当前已安装版本。
- [x] 运行离线测试、源码语法检查和 0.5.14 导出函数逐字比对，打包实验版；记录实机未验证项。

2026-10-20 收尾：39 项离线测试通过。只读审查发现的同名图层误判和同版本助手回退文件遗漏已添加先失败后通过的回归；另补助手会话防错贴。最终包只包含 23 项交付白名单文件，实际加载与无闪切仍未验收。

## 验证边界
离线测试不能证明 PS 实际无窗口切换，也不能证明未签名 External 插件能加载。两项均未经本轮实机验证，不得称已完成用户验收。
